
# Diary App - React Native

## Deskripsi
Diary App adalah aplikasi buku harian sederhana yang dibuat menggunakan React Native dan Expo. Aplikasi ini menampilkan catatan harian beserta tanggal, ringkasan cerita, dan gambar yang sesuai dengan judul diary.

## Fitur Aplikasi
- Menampilkan 5 catatan diary.
- Menampilkan judul, tanggal, dan ringkasan cerita.
- Menggunakan gambar lokal dari folder assets/moods.
- Menampilkan avatar pada bagian header.
- Menggunakan warna border berbeda untuk setiap kartu diary.
- Menggunakan komponen DiaryCard.js agar kode lebih rapi.

## Teknologi
- React Native
- Expo
- JavaScript
- React Native Safe Area Context

## Cara Menjalankan Aplikasi
1. Buka terminal pada folder project.
2. Jalankan perintah npm install.
3. Jalankan perintah npx expo start.
4. Buka aplikasi melalui Expo Go.

## Hasil
Aplikasi berhasil menampilkan lima catatan diary dengan gambar lokal dan warna border berbeda pada setiap kartu.
